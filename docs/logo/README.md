# Logo

The wordmark and the icon use outlined glyphs from [Instrument Serif](https://github.com/Instrument/instrument-serif) (SIL Open Font License 1.1). The files need no font to render.

| File | Use |
| --- | --- |
| `cook-wordmark-light.svg` | Wordmark for light backgrounds |
| `cook-wordmark-dark.svg` | Wordmark for dark backgrounds |
| `cook-icon.svg`, `cook-icon-512.png` | App icon and avatar |
| `favicon.svg`, `favicon-32.png`, `favicon-16.png` | Favicons |
| `cook-social.svg`, `cook-social.png` | GitHub social preview (1280 x 640) |

Colors: ink `#17140f`, paper `#f6f2eb`, ember `#b5461c`.
